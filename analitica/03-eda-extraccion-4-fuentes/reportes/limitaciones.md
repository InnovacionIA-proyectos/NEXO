## Vacíos ya conocidos, heredados de HU-10.2/10.3 (§12.1 del plan, sin cambios)

| Vacío | Qué impide analizar |
|---|---|
| Sin `AjusteVigenciaPlaza` aplicado | No se puede saber, solo con este extracto, qué tarifa SAP estaba realmente vigente en la práctica en cada momento |
| Sin normalización de ruta → DANE completa | Cruce geográfico fino queda limitado a una aproximación (ver L-10), no resuelto del todo |
| Ambigüedad de "tarifa vigente" (SICE-TAC y SAP) | No hay una tarifa única por ruta — cualquier comparación puntual necesita un criterio de desempate explícito |
| `tblSAPTarifasLog`: ¿tarifa ganada o auditoría? | No se puede usar como proxy de "qué tarifa se aplicó de verdad" sin confirmación de negocio |
| Volumen real bajo (13 solicitudes) | Ninguna conclusión de este EDA es generalizable a producción real |
| SICE-TAC de un solo período (en el extracto oficial) | No hay análisis de tendencia temporal posible sobre el piso SICE-TAC con el archivo entregado |
